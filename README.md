# Golf Navi

スマホのホーム画面に入れて使うゴルフアプリ（PWA）。App Store や Google Play を通さず、URL を開いて「ホーム画面に追加」するだけでインストールできます。

## できること

| 画面 | 機能 |
|---|---|
| ナビ | GPS でグリーンの手前・センター・奥までの距離、地図タップで任意地点までの距離、ハザード（池・バンカー）の手前/越えの距離、風・高低差・ライ・気温を補正した番手アドバイス、ショット地点の記録による飛距離の自動計測、ホールごとの攻略（自動生成＋AI）、マイ攻略メモ |
| コース | 全国のゴルフ場検索（OpenStreetMap 同梱データ／近くを検索／楽天GORA） |
| スコア | 1ホールずつ入力（打数・パット・FW・ペナルティ・バンカー）、OUT/IN 集計、保存・共有 |
| 動画 | 撮影 or 選択した動画に弾道トレーサー（手動3タップ＋自動検出）、トリミング、スロー、クラブ/飛距離の表示、動画の書き出し |
| 天気 | コースの16日先までの時間ごとの天気、ゴルフ日和度、天気に応じた攻め方、ウェアのコーデ提案、楽天市場の人気ウェア、おすすめショップ（随時更新） |
| 仲間 | 暗号化グループチャット、予約プランの共有、日程・コースの投票、コンペ企画（参加受付・組み合わせ・新ペリア順位表） |
| 予約 | 楽天GORA で日付ごとの最安値カレンダー、プラン一覧、予約ページへのリンク |
| 分析 | 平均スコア・パット・パーオン率・FWキープ率などの統計、目標スコアとの差から課題を順位付け、AIコーチ（課題・目標・練習メニュー）、番手別の実測飛距離 |

屋外モード（右上の太陽アイコン）にすると、直射日光の下でも読みやすい高コントラスト・大きな文字になります。ナビ表示中は画面がスリープしません。

## インストール方法

- **iPhone（Safari）**: URL を開く → 下の共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**: URL を開く → 画面下の「追加」またはメニュー → 「アプリをインストール」

初回は位置情報の許可を求められるので「許可」を選んでください（ナビの距離計測に使います）。

## 任意の設定（設定画面）

- **Claude API キー**: AI 攻略・AI コーチ・AI コーデ提案に使います。キーは各自の端末にだけ保存されます。https://console.anthropic.com/settings/keys
- **楽天ウェブサービス（applicationId / accessKey）**: 最安予約カレンダー、GORA のコース検索、ウェアの商品表示に使います。https://webservice.rakuten.co.jp/ でアプリを登録し、許可するサイトにこのアプリの URL を登録してください。

キーを入れなくても、GPS ナビ・攻略（自動生成）・スコア・分析・動画・天気・ウェア提案・仲間機能はすべて使えます。

## 情報の更新

- **ショップ紹介・季節のおすすめ**: `data/feed.json` を編集して GitHub に push すると、全員のアプリに反映されます。
- **コース一覧**: `data/courses-jp.json`（OpenStreetMap から生成）。
- **ホールのレイアウト**: 選んだコースのデータを OpenStreetMap から読み込み、14日ごとに自動で取り直します。
- **攻略メモ・グリーン位置**: 各自で更新でき、設定の「攻略メモを友だちに送る」で交換できます（新しい方で上書きされます）。

## 技術メモ

- ビルド不要の静的サイト（HTML / CSS / JavaScript モジュール）。GitHub Pages で配信しています。
- データは端末の localStorage に保存されます。動画は端末に残さず、書き出したファイルを保存・共有します。
- 地図: Esri World Imagery / コース: © OpenStreetMap contributors (ODbL) / 天気・標高: Open-Meteo / 予約: 楽天ウェブサービス / チャット中継: ntfy.sh（中身は AES-GCM で端末暗号化）
- ローカルで動かす場合: `npx serve .` などで配信し、http://localhost で開く（GPS とカメラは https か localhost が必要）。
