# KUNIKUNIゴルフアプリ

スマホのホーム画面に入れて使う、無料のゴルフアプリ（PWA）。App Store や Google Play を通さず、URL を開いて「ホーム画面に追加」するだけでインストールできます。

**https://kuniaki18.github.io/golf-navi/**

## できること

| 画面 | 機能 |
|---|---|
| ナビ | 回転ホールビュー（ティーが下・グリーンが上の航空写真）、距離の弧、グリーンの手前・センター・奥、今日のピン位置、ハザードの手前/越え、地図タップで任意地点まで（2つの距離）、自動ホール切替、GPS平均化 |
| 番手 | 風（気象データの向かい/追い/横風）・高低差（国土地理院 1m〜10m DEM）・ライ・気温で「実際に打つ距離」を補正し、マイクラブの距離から番手を提案 |
| 攻略 | ホールの形・ドッグレッグ・池・バンカー・グリーンの奥行きと幅から攻略を自動生成。AI は航空写真も読み取って詳しい攻略を作成。攻略ブック（全ホール一覧・難易度・コース全体の作戦） |
| コース | 全国のゴルフ場をアプリに同梱（オフラインで即検索）。ひらがな・略称（CC/GC）でも検索可、お気に入り、近い順、ホールデータあり絞り込み |
| 未登録コース | ホールビューで「ティー → グリーン」をタップして1ホール10秒で登録。ショット記録で回るだけでもティーとグリーンを自動で覚える |
| スコア | 1ホールずつ入力（打数・パット・FW・ペナルティ・バンカー）、OUT/IN 集計、保存・共有 |
| 今日のメンバー | 紙のスコアカードを撮影して全員の打数を読み取り（AI なら手書きも可／キーなしは端末内 OCR）、手入力、自分の行をスコアカードに反映、コンペへ一括提出 |
| 思い出 | その日の写真（端末内に圧縮保存）・メンバーの順位・天気・ひとことをアルバムとして保存、共有用の「思い出カード」画像を作成 |
| 動画 | スイングチェック（端末内で骨格を検出 → アドレス/トップ/インパクト/フィニッシュを自動判定 → テンポ・頭のブレ・スウェー・前傾キープ・左腕・体重移動などを採点、ドリル提案、履歴比較、AIコーチ）、ショットトレーサー（弾道ライン・トリミング・書き出し） |
| 天気 | 16日先までの時間ごとの天気、ゴルフ日和度、天気に応じた攻め方、ウェアのコーデ提案、ショップ紹介（随時更新） |
| 仲間 | 暗号化グループチャット、予約プランの共有、日程・コースの投票、コンペ（参加受付・組み合わせ・新ペリア順位表） |
| 予約 | 楽天GORA で日付ごとの最安値カレンダー |
| 分析 | 平均スコア・パット・パーオン率・FWキープ率・推定ハンディなど、目標スコアとの差から課題を順位付け、AIコーチ（スイング解析の結果も反映）、番手別の実測飛距離 |

屋外モード（右上の太陽アイコン）で直射日光の下でも読みやすい表示に。ナビ表示中は画面がスリープしません。

## インストール方法

- **iPhone（Safari）**: URL を開く → 下の共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**: URL を開く → 「追加」またはメニュー → 「アプリをインストール」

## 任意の設定（設定画面）

- **Claude API キー**: AI 攻略・AI コーチ・AI コーデ・AI スイングコーチ。キーは各自の端末にだけ保存。
- **楽天ウェブサービス（applicationId / accessKey）**: 最安予約カレンダー、GORA 検索、ウェアの商品表示。

キーなしでも、GPS ナビ・自動攻略・攻略ブック・スコア・分析・スイングチェック（採点とドリル）・トレーサー・天気・ウェア提案・仲間機能はすべて無料で使えます。

## データの更新

- **全国コースデータ**: `tools/extract.mjs` で OpenStreetMap の日本全域データ（Geofabrik）から生成 → `data/courses-jp.json`（一覧）と `data/c/<id>.json`（ホール配置）。
  ```
  curl -L -o japan-latest.osm.pbf https://download.geofabrik.de/asia/japan-latest.osm.pbf
  curl -L -o tools/japan-pref.geojson https://raw.githubusercontent.com/dataofjapan/land/master/japan.geojson
  npm i --prefix tools
  node --max-old-space-size=12000 tools/extract.mjs japan-latest.osm.pbf data
  ```
- **ショップ紹介・季節のおすすめ**: `data/feed.json` を編集して push。
- **攻略メモ・登録したホール・グリーン位置**: 設定の「攻略メモを友だちに送る」で交換（新しい方で更新）。
